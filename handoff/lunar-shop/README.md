Откройте [инструкцию по переносу в Unity](UNITY-HANDOFF.md). Она покрывает все этапы актуального прототипа, от новой игры до обеих историй после ярмарки.

| Что реализуете | Где смотреть правила и проверку |
|---|---|
| Репутация, открытия, доска заказов, ярмарка и события | [Заказы и прогрессия](UNITY-ORDERS.md) |
| Сад, лаборатория, очереди, инвентарь, магазин и улучшения | [Производство и торговля](UNITY-PRODUCTION.md) |
| Главное меню, слоты, офлайн-прогресс и переходы | [Состояние, навигация и тесты](UNITY-STATE-AND-TESTS.md) |
| Составы, цены, длительности, ключи и стартовые наборы | [Данные из всех трёх прототипов](UNITY-DATA.json) |
| Экран, состояние и файл спрайта | [Карта спрайтов](ASSETS.md) |
| Обоснование правил и баланс | [Геймдизайн](GAME-DESIGN.md) |

## Как открыть прототип

Скачайте ветку кодом или через **Code → Download ZIP**. В папке `handoff/lunar-shop` откройте нужный HTML в браузере. Папки `Спрайты` и `Шрифты` должны лежать рядом с HTML.

| Файл | Сценарий |
|---|---|
| [prototype.html](prototype.html) | Обычная новая игра и стартовая прогрессия |
| [prototype-stocked.html](prototype-stocked.html) | Начальный прогресс, 999 монет и запас предметов |
| [prototype-unlocked.html](prototype-unlocked.html) | Открытые механики, включая куб, и запас предметов |

При повторной проверке выберите новый слот. Прототип показывает целевое поведение и оформление. Сценарии переноса в Unity описаны отдельно.
